# Applied AI Engineering Bootcamp Handbook
### A Production-Grade, Project-Based Path from Backend Engineer to AI Engineer

---

## How to Use This Handbook

This is a living document, delivered **one module at a time**. Each module is a
self-contained file you can read, practice, and revisit. Modules build on each
other in strict order — don't skip ahead, even if a topic looks familiar,
because later exercises assume the vocabulary and mental models from earlier
ones.

**Pace:** ~2–3 hours/day → roughly 9–12 months for the full handbook, working
through PART 0 → PART 11 in order. You can compress this if you dedicate more
hours, or run AI Foundations (Part 2) in parallel with Software Engineering
Foundations (Part 1) once you're past Part 0.

**Format per module:** objectives → theory (20%) → implementation (80%) →
resources → exercises → mini-project → production project → interview
questions → checklist → next steps.
